# From Rules to Agents

An interactive 8-hour AI foundations course: session plan, trainee and instructor notes, 14 hands-on activities, module checks, a timed final assessment and a certification framework.

Live site: `https://<your-username>.github.io/<repo-name>/`

Everything is in one file, `index.html`. No build step, no dependencies.
Trainee progress is stored in each visitor's own browser (localStorage).
